# VOYRA AI 여행 플래너

예산, 기간, 여행 취향을 조절하면 추천 목적지와 일정 카드가 실시간으로 바뀌는 인터랙티브 랜딩페이지입니다.

## 파일 구성

- `index.html` — 메인 페이지
- `styles.css` — 반응형 레이아웃과 스타일
- `script.js` — 추천 로직과 인터랙션

`index.html`을 브라우저에서 바로 열거나 아래 명령으로 로컬 서버를 실행할 수 있습니다.

```bash
npm install
npm run dev
```

배포용 파일은 `npm run build` 실행 후 `dist/`에 생성됩니다.
